# Tafel 分析器

这是一个 Windows/PyQt6 桌面分析软件：导入 CHI604E 风格的 `.txt`（也可读取同样表头的 `.csv`），由手动指定的阴极和阳极电位区间进行 Tafel 线性拟合，并支持批量、项目恢复、趋势分析和结果导出。

程序计算的纵轴严格为 `log10(abs(I) × 1000 / S)`，也就是 **`log10[j/(mA cm^-2)]`**；横轴为电位 `E (V)`。其中 `I` 是文件中的 `Current/A`，`S` 是面积（cm²，默认 1.13）。不会使用仪器导出的 `log(i/A)` 列。

## 使用

Windows 程序固定为 `dist/TafelAnalyzer.exe`，桌面快捷方式为“Tafel 分析器”，双击即可运行，无需安装 Python。内置合成示例已打包在程序中。

本项目只保留一个维护版本。后续功能改动直接更新当前源码、上述程序和同一个桌面入口；构建和验证文件使用固定目录与名称。

## 界面内帮助与版本信息

主窗口“帮助”菜单提供可滚动的“快速开始”和“关于”。帮助文本内置于应用，独立 EXE 运行时也无需网络、README 或其他外部文件；其中的文件名/链接仅供选择复制，不会自动打开网页、发送信息或执行链接。

当前应用版本为 **1.0.0**，也是唯一维护版本。此版本包含手动单文件/批量 Tafel 分析、图上选区、项目恢复、导出、模板、趋势与实验信息功能；不会自动检查、下载或安装更新，也不会生成第二版本或安装器。帮助会明确说明：当前仅通过合成 CHI 样例和自动化测试验证，尚未完成真实 CHI604E 数据与 Origin 人工拟合结果的逐例对照。

界面采用统一的桌面应用配色：蓝色按钮用于导入、计算和更新分析，绿色按钮用于趋势分析，浅蓝按钮用于导出。按钮悬停、按下、键盘焦点和不可用状态均有不同显示；输入框、下拉框、复选框和数据表也会反馈当前可编辑、选中或禁用状态。

1. 点击唯一的“导入文件 / 文件夹…”按钮：菜单可选择文件（支持多选）、选择文件夹、打开批量工作区或打开合成示例。也可以把本地文件或文件夹直接拖到主窗口或批量工作区。
2. 填写电极面积（cm²），确认阴极、阳极各自的电位上下限（V）。鼠标滚轮不会更改面积或区间，避免误触；数值可直接键入或点输入框旁的箭头调节。启动默认阴极区间为 `-0.12～-0.06 V`，阳极区间为 `0.06～0.12 V`；批量工作区沿用主窗口的当前区间。也可点“框选阴极”或“框选阳极”后在曲线图上拖动：边界会自动排序，且必须覆盖至少 3 个不同电位点才会写回输入框。按 `Esc` 或“取消框选”会放弃本次选择；缩放/平移工具开启时，先退出工具再框选。
3. 点击“按当前范围计算”，查看拟合线、R²、交点和交换电流密度。结果卡还会说明两支路的拟合点数、手动区间、交点是否落在全部导入数据电位范围内、相对各选区的外推距离和导入跳过行数。这些是帮助人工判断选区的事实提示：程序不会仅按 R² 自动判定好坏，也不会把位于阴阳极选区之间的正常外推交点当作错误。
4. 更换文件或修改参数后，重新点击计算。
5. 如需在其他软件绘图，在“绘图数据导出”中设置独立的电位上下限，点击“导出 Excel (.xlsx)”。这不需要先完成拟合。
6. 如需直接用于报告或论文，先完成单样品拟合后点击“导出论文级拟合图…”。批量工作区可点击“导出样品对比图片…”并勾选样品；可设置标题、坐标轴标题、图宽高、字号、线宽、图例与原始/拟合曲线显示，并导出 PNG、TIFF、PDF 或 SVG。PNG/TIFF 默认 600 dpi。
7. 如需一次处理多个文件，使用同一导入菜单的“打开批量工作区”，或直接选择/拖入文件夹。批量窗口与主窗口的单文件拟合互不覆盖。
8. 通过顶部“项目”菜单的“保存项目…”或“打开项目…”保存/恢复完整分析会话。

## 实验信息与可追溯性

通过“项目 → 编辑单样品实验信息…”可填写样品名称、实验日期、测试条件、参考电极和备注；批量工作区选择一行后可点击“编辑选中样品实验信息…”。原始文件名与完整源路径始终独立保留，不会因自定义样品名而被替换。实验信息只用于溯源：编辑会提示项目尚未保存，但不会重算或使已有拟合结果过期。

实验信息会写入 `.tafelproj`、单文件 Excel 的“说明”表、批量 Excel“汇总”表尾部，以及趋势 Excel“输入与溯源”表；文本会按 Excel 公式安全规则保存。旧版项目没有这些字段时仍可打开，并自动使用原始文件名作为样品名称。趋势分析会保留可辨识的自定义样品名称；若成功样品的参考电极为空或不一致，界面只显示非阻塞提示，保留原始数据且绝不自动进行电位换算或可比性推断。

## 参数模板与启动默认

顶部“参数模板”菜单可将当前电极面积、阴极/阳极手动区间和 Excel 导出范围保存为命名模板，也可明确加载、删除、设为启动默认或取消启动默认。模板保存在当前 Windows 用户的 `LocalAppData\TafelAnalyzer\parameter_templates.json`，独立于 `.tafelproj`：项目文件不会包含或修改这些个人常用设置。

没有启动默认模板时，软件仍使用面积 `1.13 cm²`、阴极 `-0.12～-0.06 V`、阳极 `0.06～0.12 V` 和导出 `-0.2～0.2 V`。加载模板必须由用户明确操作，并会使当前单文件拟合结果过期；打开 `.tafelproj` 时始终以项目保存的参数为准，不会被本机模板覆盖。保存同名模板或删除模板都会要求确认。模板文件采用原子写入；若文件损坏，软件会提示并保留原文件，不会用新的模板静默覆盖它。

批量窗口也可从“参数模板（本机）”加载到公共参数和批量导出范围，但这一步不会改动任何样品或成功结果；仍需明确点击既有的“应用公共参数到全部行”。选中行存在未保存草稿时，批量加载模板会停止并要求先保存或放弃草稿。

以下命令供源码开发使用，运行成品不需要执行：

安装依赖后运行：

```powershell
python -m pip install -r requirements-lock.txt   # 推荐：锁定版本
# 或者：python -m pip install -r requirements.txt
python tafel_analyzer.py
```

点击“打开合成示例”可以立即查看内置的 `samples/synthetic_chi_case1.txt`。该文件是带符号电流的**合成验证数据**，不是实际实验文件。其电位仅覆盖 `-0.07～0.07 V`，拟合此示例时请将阴极区间设为 `-0.06～-0.03 V`、阳极区间设为 `0.03～0.06 V`。

导入后确认面积及两个手动范围，点击“按当前范围计算”。程序显示两支路的 `a`、`b`、R²、点数，以及交点 `Eeq`、`log(j0)`、`j0 (mA cm^-2)`；图中显示原始点、两条向交点外推的拟合线和交点。修改文件、面积或任一拟合范围后，旧拟合结果会标为过期，必须重新计算。修改导出范围不会使拟合结果失效。

## 绘图数据 Excel 导出

导出范围默认是 `-0.2` 至 `0.2 V`，与阴极/阳极拟合范围相互独立。导出会保留导入后的原始采集顺序，并包含上下限在内的所有点；即使只选到 1 个点也可以导出。

工作簿的“绘图数据”工作表第一行固定为两列：`Potential (V)` 和 `log10[j/(mA cm^-2)]`。后续行均为数值单元格，没有原始 `Current/A`、仪器的 `log(i/A)` 或拟合线数据。第二个“说明”工作表记录来源、当前面积、范围、公式和跳过行数。每次导出都用**当前面积**重新计算 `log10(abs(I) × 1000 / S)`，因此更改面积后无需拟合也可以重新导出。保存时先写入同目录临时文件，再原子替换目标；若 Excel 正在打开目标文件，请关闭后重试。

保存对话框默认给出 `.xlsx` 文件名；若手动输入没有 `.xlsx` 的名称，程序会在该名称后追加 `.xlsx`，不会替换原有扩展名。

## 统一导入规则

显式选择一个 `.txt` 或 `.csv` 文件时，会打开既有的单文件曲线与拟合界面。选择多个显式文件，或选择/拖入一个文件夹时，会进入批量工作区；即使文件夹只有一个 TXT，也按批量处理。文件夹会递归查找 `.txt`（不区分大小写），按稳定的完整路径顺序导入，不读取文件夹中的 CSV，并且不会跟随符号链接或 Windows 联接。

同一次选择中的重叠路径、重复文件，以及已经在批量工作区中的相同绝对路径都会去重，因此重新导入同一文件夹不会清除已有行、参数或成功结果。不存在、不可读、空文件夹、不支持的类型和非本地拖放 URL 会以提示显示；其他有效文件仍会继续导入。导入文件夹时 CHI 解析失败的文件会保留为“导入失败”行，便于追溯完整源路径。

## 批量分析与导出

批量窗口使用同一“导入文件 / 文件夹…”菜单，也接受本地文件和文件夹拖放；没有固定的小批次数量限制。手动“选择文件…”保留 `.txt`/`.csv` 多选支持，手动“选择文件夹…”和文件夹拖放递归寻找 TXT。每个文件独立导入：损坏文件会保留为“导入失败”行，其余文件仍可继续计算。表格显示文件名、完整源路径、状态、错误、`Eeq`、`log(j0)`、`j0` 和两支路 R²；因此即使不同目录有同名文件也能区分。

打开批量窗口时，主窗口当前面积、阴极/阳极范围会作为公共初值。可以将公共参数应用到全部行，也可以选中某一行单独调整面积和两个手动区间，并在右侧预览该行曲线、选区和拟合。选中行详情会显示相同的人工质量提示（点数、R²、范围、交点位置/外推距离和跳过行），不改变成功状态或趋势纳入逻辑。选中行同样可图上框选；它只会进入当前行的未保存草稿，预览会明确显示草稿并隐藏旧拟合线，不会静默改动其他行或成功结果。点击“保存选中行参数”后才使该行拟合过期。切换到另一行时，软件会要求保存、放弃或取消切换，防止草稿丢失。运行全部时失败行会记录错误，已经成功的其他行不会被覆盖。

“批量结果管理”可按全部、成功、失败或待计算状态筛选，并按文件名或完整来源路径搜索；筛选只隐藏表格显示行，不会重排或改变内部样品对应关系。可将选中样品从当前应用列表移除，程序会明确确认且不会删除、移动或修改原 TXT/CSV 源文件。也可重新导入选中样品：程序会先解析候选源文件，解析失败时保留原有数据、拟合结果和状态；检测到源数据变化时必须再次确认，确认后才只替换该行数据、使其结果变为待计算，并让趋势设置过期。未保存的选中行参数草稿不能被这些操作静默覆盖。

批量 Excel 的“汇总”表包含唯一 Sample ID、样品文件名、完整源路径、状态/错误、每行参数、拟合数值和绘图表映射。每个已成功导入的文件都有独立且唯一命名的绘图表，仅包含 `Potential (V)` 与 `log10[j/(mA cm^-2)]` 两列数值，并按该行面积重新计算。批量绘图范围独立于拟合范围；个别文件在该范围内没有点时，会在汇总表的 Plot status 中注明，但其他文件仍会导出。

## 论文图片导出

单样品图片只会在当前 Tafel 拟合有效时导出，包含所选的原始 `log(j)` 曲线、两支真实拟合线和交点。批量对比图按每个样品自己的电极面积重新计算 `log(j)`；用户可勾选有数据的样品。待计算或拟合失败的行最多只会作为原始曲线显示，软件不会为它们推断、绘制或标记为成功拟合。选中行存在未保存参数草稿时，批量图片导出会先停止，避免将草稿和已保存结果混在同一成品图中。

支持 PNG、TIFF、PDF 和 SVG。PNG/TIFF 默认 600 dpi，PDF/SVG 为矢量格式；图片写入同目录临时文件后原子替换。取消保存不会创建文件；若规范化后的目标已存在（包括补全后缀后），软件会明确要求覆盖确认。

## 分析项目保存与恢复

“保存项目…”会让用户选择一个独立的 `.tafelproj` 文件；这不是 TXT 源文件或 Excel 导出，因此不会替换原始实验数据。文件采用版本化 JSON，写入同目录临时文件后原子替换目标；已有项目会先要求确认覆盖。项目会保存单文件和批量工作区的独立面积/选区、已导入的解析后电位/电流快照、每行状态和可验证拟合结果，以及趋势分析的纳入、标签、分组、数值横轴、设置和基准。

恢复时程序使用项目内嵌快照，而不是悄悄重新读取原 TXT 路径；界面会明确说明这一点，并保留原源路径供追溯。因此源文件移动、丢失或之后被改写不会让恢复结果混入其他数据。带有已计算结果的项目会重新计算，并与保存的拟合数值核对；校验失败、格式损坏或不兼容版本会在替换当前会话之前被拒绝，当前会话不会被清空。选中行参数草稿、运行中的批量计算不能保存，必须先完成或保存草稿。关闭软件时如有未保存单文件、批量或趋势更改，会提供保存、放弃或取消；取消保存/保存失败会保持窗口打开。

## 批量趋势分析

批量计算完成后，点击“趋势分析…”可将当前成功结果建立为只读快照。默认按不同样品或处理条件分别比较；同名文件不会自动认作重复实验，每条记录都有独立的 `S001 文件名` 分组，需要时可在表格中手动改为同一分组。趋势图同时显示单次结果、分组算术均值和样本标准差（`n=1` 不显示 SD）；结果表也会列出 `mean[log10(j)]` 与 `log10(mean[j])`，两者不混用。

也可选择数值横轴并填写时间、循环数、浓度等数值；相同“分组 + X”会汇为重复实验。数值横轴可选择显示描述性线性回归，但不输出显著性、因果结论或自动最佳样品。可选的 R² 阈值仅用于透明筛选，不是 Tafel 区域有效性的自动判定。

分析语义须由用户明确选择：默认“交换电流密度 `j0`”用于反应动力学比较，数值变大不自动表示腐蚀更严重；“腐蚀电流密度 `jcorr`”只应在同一腐蚀体系和可比条件下解释，较小值对应较低的均匀腐蚀电流。选择一个汇总点作基准后，会显示密度比 `j/jref` 和相对变化；腐蚀语义下还显示 `IE=(1-j/jref)×100%` 与 `IP=10log10(jref/j)` dB，负 IE 不会被截断。趋势 Excel 会保存输入溯源、筛选原因、分组汇总、基准比较、回归和设置，不包含原始电流。

方法依据和解释边界见 [TREND_METHODS.md](TREND_METHODS.md)。本工具不会据 Tafel 结果自动换算腐蚀速率；该换算还需要材料当量、密度和均匀腐蚀假设。

输入须有 `Potential/V` 和 `Current/A` 表头（无单位的 `Potential`/`Current` 默认按 V/A 解释；明确标为 mV/mA 的列会拒绝），支持逗号、Tab 或空格分列，科学计数法，以及 UTF-8 BOM/GB18030。零电流、非有限数和格式错误行会明确计数并跳过。若含正反扫方向反转，MVP 会拒绝导入，以免把重复电位的正反扫静默混合。

## 构建 Windows EXE

```powershell
.\build.ps1
.\dist\TafelAnalyzer.exe
```

构建脚本默认复用项目的 `.venv`（可用 `-PythonExe` 指定解释器；没有可用解释器时创建 `.build-venv`），按 `requirements-lock.txt` 安装锁定依赖，并更新单文件、无控制台窗口的 `dist/TafelAnalyzer.exe`。构建前关闭正在运行的程序，以便替换同一文件。可作无界面包装检查：

```powershell
.\dist\TafelAnalyzer.exe --self-test
```

自检会加载内置示例、完成拟合和绘图、验证单文件绘图数据 Excel、混合批处理及 XLSX 汇总/绘图表、趋势图和 Excel、PNG/TIFF/PDF/SVG 拟合图，并检查临时文件夹的导入拖放路由和内置离线帮助，成功时退出码为 0。自动化测试使用合成数据与已知参考公式；尚无实际 CHI604E 数据及 Origin 对照结果。当前不支持 XLSX 原始数据导入或自动挑选 Tafel 区域。

为了缩小下载体积，可选用 Windows x64 [UPX 官方发行版](https://github.com/upx/upx/releases)。将压缩包解压后，把其中含 `upx.exe` 的目录传给构建脚本，例如：

```powershell
.\build.ps1 -UPXDirectory "C:\tools\upx-5.3.0-win64"
```

也可将 `upx.exe` 所在目录加入 `PATH`。如果未找到 UPX，程序仍会正常构建，但文件会较大。UPX 可能增加启动时解压时间，个别安全软件也可能对压缩包产生误报；分发前建议扫描最终 EXE。UPX 只用于构建，不包含在分析器里。
